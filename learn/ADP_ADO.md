# EtherCAT 协议中 ADP、ADO 的核心作用
ADP 和 ADO 是 EtherCAT 物理寻址子报文（Datagram）的核心地址字段，二者配合完成「定位目标从站 → 访问从站内部寄存器」的两级寻址，是 EtherCAT 主站直接访问从站 ESC（EtherCAT 从站控制器）寄存器的底层基础，也是总线初始化、设备配置、非周期通信的核心。
## 一、官方定义与基础定位
1. 全称与字段属性
表格
字段	官方全称	位宽	核心定位
ADP	Auto Increment / Fixed Physical Address（自动增量地址 / 固定物理地址，也叫 Address Position 地址位置）	16 位	负责定位总线中的目标从站
ADO	Address Data Offset（地址数据偏移，也叫寄存器地址偏移）	16 位	负责定位从站内部的具体寄存器 / 内存地址
2. 整体寻址逻辑
EtherCAT 物理寻址的子报文头中，ADP 和 ADO 是两个独立的 16 位地址字段，二者形成两级寻址：
第一级：通过 ADP 找到总线上的目标从站（单个 / 多个 / 全部）；
第二级：通过 ADO 找到该从站 ESC 寄存器空间内的具体地址，完成读写操作。
## 二、ADO 的固定作用（全寻址模式通用）
ADO 的作用在所有物理寻址模式下完全一致：指定从站 ESC 寄存器空间的 16 位起始访问地址，是访问从站内部内存的唯一地址标识。
关键细节
地址空间范围：ESC 的寄存器空间为 64KB（0x0000 ~ 0xFFFF），分为两个核心区域：
0x0000 ~ 0x07FF：ESC 通用寄存器区，包括 AL 状态机控制 / 状态寄存器、同步管理器（SM）配置、FMMU 配置、站地址配置寄存器等，是主站配置从站的核心区域；
0x0800 ~ 0xFFFF：用户 DPRAM 数据区，用于存放 PDO 过程数据、SDO 邮箱数据、用户自定义数据等。
连续地址访问：ADO 指定起始地址后，配合数据长度，可一次性读写多个连续的寄存器 / 内存地址，大幅降低通信开销。
典型示例：
访问从站 AL 状态寄存器，ADO 设为 0x0130；
配置从站固定地址，ADO 设为 0x0010（站地址配置寄存器）。
## 三、ADP 的作用（随寻址模式变化）
ADP 的核心是定位目标从站，具体行为完全*取决于子报文的寻址类型（EtherCAT 命令类型）*，分为三大场景：
1. 固定物理寻址（FPRD/FPWR/FPRW 命令）
ADP 作用：存储目标从站的 16 位固定物理地址（Configured Station Address）。
核心规则：每个从站都有唯一的固定物理地址（主站初始化阶段分配，或通过拨码开关硬件设置），只有地址与 ADP 完全匹配的从站，才会处理这个子报文。
典型场景：总线运行阶段，主站对单个从站进行参数配置、SDO 读写、寄存器读写等精准操作。
2. 自动增量寻址（APRD/APWR/APRW 命令）
ADP 作用：存储自动增量位置计数器，通过从站在总线中的物理拓扑位置寻址，不依赖固定地址。
核心规则：子报文每经过一个从站，从站的 ESC 会自动将 ADP 的值减 1；只有当 ADP 减到 0 时，当前从站才会处理这个报文，否则直接转发给下一个从站。
示例：要访问总线中第 3 个从站，主站发送时 ADP 设为 3：
第 1 个从站：ADP 减到 2，不处理，直接转发；
第 2 个从站：ADP 减到 1，不处理，直接转发；
第 3 个从站：ADP 减到 0，处理报文。
典型场景：总线初始化阶段（从站还未分配固定地址），扫描从站数量、给从站分配固定物理地址、批量读取从站基础信息。
3. 广播寻址（BWR/BRD/BRW 命令）
ADP 作用：固定设为 0xFFFF，表示广播地址。
核心规则：总线上所有从站都会处理这个子报文，工作计数器（WKC）会累加所有处理报文的从站数量。
典型场景：批量操作所有从站，比如广播下发控制指令，让所有从站同步切换 AL 状态机（INIT→PREOP→SAFEOP→OP），保证多设备同步性。
## 五、关键补充说明
1. 与逻辑寻址的区别：
ADP/ADO 仅用于物理寻址，核心用于非周期的初始化、配置、寄存器访问，针对单个 / 多个从站；
**周期过程数据（PDO）传输通常使用逻辑寻址（LRD/LWR/LRW 命令），采用 32 位逻辑地址，通过 FMMU 映射到从站内存，不使用 ADP/ADO。**
2. 权限与约束：
ADP/ADO 是 EtherCAT 主站协议栈的底层接口，正常应用开发通常通过 CoE/SDO 等应用层协议间接使用，无需手动操作；
自动增量寻址依赖总线物理拓扑，从站顺序变化后，ADP 的值需要同步调整。
3. 常见误区纠正：
ADP/ADO 不是 PDO 的地址组成部分，PDO 映射基于逻辑地址和 FMMU，与 ADP/ADO 无关；
ADO 是从站 ESC 的物理寄存器地址，不是对象字典的索引 / 子索引，SDO 通信的底层仍通过 ADP/ADO 访问邮箱寄存器实现。
